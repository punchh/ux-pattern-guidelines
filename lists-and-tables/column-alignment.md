# Column alignment

{% hint style="success" icon="sparkles" %}
[**Get the AI skill**](column-alignment.md#ai-skill-file) for this UX pattern guideline in a markdown (.MD) file.
{% endhint %}

Humans best comprehend tabular data when values are aligned predictably in a way that facilitates comparison.

Data type or format is the best determinant of alignment.

<figure><img src="../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure>

### Left-aligned data types

* Names
* Titles
* Unique identifiers (codes, alphanumeric combos, even straight numeric IDs)
* Stacked text
* Dates (yes, dates)
* Times
* Phone numbers
* Zip codes

### Right-aligned data types

* Dollar values
* Percentages
* Rates
* Counts
* Sizes

### Center-aligned data types

* Strictly boolean values (e.g. Yes/No, a “flag”, etc.)
* Checkboxes (which is the same thing as boolean...)
* Statuses represented by a tag, pill, or chip
* Image content
* Single-iconographic representations
