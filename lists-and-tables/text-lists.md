# Text lists

### Bulleted lists

Use a bulleted list when items are related but their order or priority doesn’t matter.

✅ **Precede the list with a declarative phrase** or sentence followed by a [colon](../reading-information/grammar-voice-and-tone.md#colons)

✅ **Capitalize the first letter** in the first word of each bullet (sentence case)

✅ **Okay to substitute a bullet with an emoji or icon** only when relevant and using the same emoji or icon on each bullet

🚫 **No commas** at the end of any bullet

#### Example

```
If you delete your account:
• You will no longer be able to sign in with your account
• You will no longer be able to see receipts of all of your past orders
• You will no longer be able to order delicious meals from our restaurants
```

### Numbered lists

Use a numbered list when item sequence or priority matters, such as step-by-step instructions.

✅ **Capitalize the first letter** in the first word of each numbered item (sentence case)

🚫 **No commas** at the end of any numbered item

#### Example

```
How it works
1. Add your vehicle details
2. Pull into a Curbside parking spot
3. Tap the I'm here button
4. We’ll bring your order right out
```
