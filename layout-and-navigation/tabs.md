# Tabs

{% hint style="success" icon="sparkles" %}
[**Get the AI skill**](tabs.md#ai-skill-file) for this UX pattern guideline in a markdown (.MD) file.
{% endhint %}

Tabs are effectively our secondary navigation menu system. Each tab menu group is unique to the active/selected primary navigation (left nav).

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (241).png" alt=""><figcaption></figcaption></figure></div>

### Layout and interaction

* Left-aligned only 
* On smaller viewports, swipe to access out-of-view horizontal tabs 
* Tabs on top, content and form controls for each tab underneath (no bottom tabs) 
* Never nest horizontal on horizontal, nor vertical on vertical tabs (use accordions at the lower level instead)

### Use tabs when:

#### ✅ On dense, read-only informational pages to organize content

Tabs make for a good alternative to subheadings if the information doesn’t need to be seen together at the same time 

#### ✅ On an Edit page with many form fields

 Again, tabs make a good alternative to subheadings 

#### ✅ As a top-level filter on table and list pages

 Think of tabs as a way to separate items in the list that never need to be mixed together 

#### ✅ Horizontally when there are about 2-6 tabs 

Any more than that might necessitate rethinking your information architecture

### Don't use tabs when:

🚫 Information across tabs needs to be seen at the same time 

🚫 If a tab will only have just 1 piece of information  or field (find a way to group this in another tab instead)

🚫 Tabs are redundant to other navigation 

🚫 There’s so many tabs they need to wrap into a second row in a narrow desktop viewport . Rethink your information architecture or use vertical tabs in this case.

🚫 Any tab label is longer than 2 words max (ideally, shoot for 1 word tab labels) 

🚫 There's a dropdown list built into any tab

🚫 If you're trying to use tabs to facilitate a mutually exclusive selection. Moreover, don't use tabs as a form field. Tabs are not a form field. The pattern you want for this is a [button group](../entering-information/button-groups.md) with accompanying [conditional fields](../entering-information/conditional-fields.md).
