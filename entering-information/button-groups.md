# Button groups

{% endhint %}

{% hint style="info" %}
Button groups, grouped buttons, and segmented control fields are all the same thing
{% endhint %}

### Usage

* For single-select situations only
* Useful with about 2-6 options to choose from when each option is exactly 1 or 2 words of similar length
  * When there are more options to choose from, use a [dropdown list](dropdown-lists.md) or [combo box](combo-box-fields.md)
  * When the options are more variable in length, or have too many characters to elegantly or symmetrically fit, use a [radio button field](radio-button-fields.md)

### Behavior and layout

* Like a [radio button field](radio-button-fields.md), the user cannot deselect a selection
* Options always follow a 1-row horizontal layout
* The visual design should be distinct from regular form buttons (or chips), such that the buttons in a button group are visually tightly grouped together
