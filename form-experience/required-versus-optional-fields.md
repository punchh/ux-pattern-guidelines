### Usage

#### ✅ Always mark required fields with an asterisk 

Doesn’t matter if there are more required fields than optional fields. 

#### ✅ An asterisk symbol is enough 

No need for the word “Required”.

#### ✅ Make the asterisk a color different than the field label font 

Doesn’t need to specifically be red or blue, but use some distinguished color.

#### ✅ No need for instructions 

You don’t need to explain that \* means required. Not at the top, not at the bottom.

#### ✅ Make sure screenreaders announce “required” rather than “asterisk” 

We do this for accessibility. Accomplished in the code via engineering markup.
